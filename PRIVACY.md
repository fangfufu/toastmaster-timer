# Privacy Policy

This application does not collect, store, or transmit any personal data or usage information.

## No Data Collection
No data is collected by this application. All session-related information (such as roles, names, and timing data) remains entirely within your browser or on your local device. 

## Local Storage
Any data you enter or timers you run are stored only in your browser's temporary memory. If you use the "Save Session" feature, the data is exported to a file on your own device; it is never uploaded to a server.

## Third-Party Resources
The app loads some resources (fonts, icons, and libraries) from Content Delivery Networks (CDNs). These services may see your IP address and browser metadata as part of the standard web request to deliver those files, but no application-specific data is shared with them.

## Offline Processing
This app is designed as a Progressive Web App (PWA) and can function entirely offline.
