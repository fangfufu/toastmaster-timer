# ⏱️ Toastmasters Timer

A premium, full-screen countdown timer designed specifically for Toastmasters timekeepers. Ensure every speaker stays within their limits with high-visibility color transitions and an elegant, distraction-free interface.

![Toastmasters Timer Showcase](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/timer.svg) <!-- Placeholder for a real screenshot if available -->

## ✨ Features

- **🎯 Configurable Thresholds**: Set custom Green, Amber, and Red time limits for any speech type (Prepared Speeches, Table Topics, Evaluations).
- **🎨 Dynamic Transitions**: The entire screen transitions between colors, providing a clear visual cue that is impossible to miss.
- **📱 Screen Wake Lock**: Integrated Screen Wake Lock API ensures your device stays awake throughout the entire session.
- **💎 Premium Design**: Clean, modern aesthetics featuring glassmorphism, smooth animations, and high-contrast typography.
- **📊 Session Summary**: Review the exact duration of each segment immediately after finishing.
- **⚡ Zero Setup**: Runs entirely in the browser. No installation or account required.

## 🛠️ Tech Stack

- **Core**: HTML5 Semantic Markup
- **Logic**: Vanilla JavaScript (ES6+)
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Typography**: Inter (Google Fonts)

## 🚀 Getting Started

You can use the [Live Demo](https://fangfufu.github.io/toastmaster-timer/) or run it locally by opening `index.html` in any modern web browser.

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/fangfufu/toastmaster-timer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd toastmaster-timer
   ```
3. Open `index.html` in your browser:
   ```bash
   # On macOS
   open index.html
   # On Linux
   xdg-open index.html
   ```

## 🎨 Design Philosophy

The Toastmasters Timer is built with a **"Visual-First"** approach. By leveraging the **Screen Wake Lock API**, it guarantees reliability during long sessions. The UI uses a deep slate background with glassmorphic cards and vibrant, accessible color states (`#22c55e`, `#f59e0b`, `#ef4444`) to ensure maximum legibility for the speaker from across the room.
